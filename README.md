# Treino V4 — Mobile

PWA móvel para registrar treino Upper/Lower, carga, repetições e RIR.

## Recursos
- Upper A / Lower A / Upper B / Lower B
- Fase de retorno por semana
- Registro série a série
- Histórico e resumo semanal
- Timer de descanso
- Backup JSON e exportação CSV
- Armazenamento local no navegador

## Instalação no iPhone
Abra o site publicado no Safari e use **Compartilhar → Adicionar à Tela de Início**.
